# 1.5.0 publication verification

Date: November 7, 2026, America/Los_Angeles.

## Published package

[PyPI 1.5.0](https://pypi.org/project/streamlit-shadcn-ui/1.5.0/) contains the
wheel and source archive built for the release. Both files were downloaded
again from PyPI and matched the local artifacts byte for byte. Their SHA-256
hashes match PyPI metadata and the release notes.

Release source: [feat: release v1.5.0 component composition and data table](https://github.com/ObservedObserver/streamlit-shadcn-ui/commit/1bb90bd2a6712621ece162ab561034055e103600),
November 7, 2026, [PR #62](https://github.com/ObservedObserver/streamlit-shadcn-ui/pull/62).

- 110 Python tests and 147 frontend tests passed after the version update.
- Generated-source, import graph, Shadow CSS, TypeScript, production build,
  distribution and archive checks passed. Both archives passed `twine check`.
- The production JS and CSS match the accepted P0 component assets.
- A clean environment reinstalled 1.5.0 from the public PyPI index with
  `--no-cache --reinstall`. Imports resolved to its `site-packages`; no
  `direct_url.json` referred to a local package checkout.
- Apps ran outside the library source checkout. All 55 documentation apps
  mounted with the installed public package without Python exceptions.

The host was Python 3.14.2, Streamlit 1.60.0, Starlette 1.3.1, AnyIO 4.16.0
and Uvicorn 0.54.0.

Community Cloud's configuration uses Python 3.10. A second clean environment
using Python 3.10.9 installed the documentation requirements from PyPI and ran
all 55 documentation apps without Python exceptions.

| Published-package browser suite | Passing cases across Chromium, Firefox and WebKit |
| --- | ---: |
| Sheet | 21 |
| Elements containers | 6 |
| Item | 3 |
| Data Table, including Sheet edit/save | 15 |
| Total | 45 |

The first local-wheel startup exceeded a 10-second visibility assertion while
Streamlit was still running the app. A subsequent complete Data Table run
passed all 15 cases. In the public-package run, a Firefox containers case
clicked a tab while a native rerun was reordering the tab tree. Trace review
showed the old selected-tab assertion passed before the new order arrived.
The test now waits for the reordered tree before clicking. All six containers
cases passed with that correction. No package runtime or published artifact
changed during either investigation.

## Documentation publication

[Documentation PR #3](https://github.com/ObservedObserver/streamlit-shadcn-ui-docs/pull/3)
merged on November 7, 2026. Requirements pin the published package 1.5.0,
Streamlit 1.60.0 and Starlette 1.3.1. All 108 mirrored source and support files
matched the release source before merging. Homepage and Getting Started read
the installed distribution version.

GitHub delivered the main-branch push to the active Streamlit webhook and
received HTTP 200, but the site initially kept serving 1.4.0. The authenticated
Cloud console showed the historical repository name `steamlit-shadcn-ui-docs`,
main branch, `Home.py`, and Python 3.10. GitHub confirmed the historical and
current names resolve to the same repository ID and merged commit; no second
deployment repository was created. A manual reboot of the existing app caused
the new source and package to load. No hosting settings were changed.

Live checks at [shadcn.streamlit.app](https://shadcn.streamlit.app/) passed:

- Getting Started reported `Installed package: streamlit-shadcn-ui 1.5.0`
  from distribution metadata. The app menu reported Streamlit 1.60.0.
- Homepage's runtime release card reported 1.5.0 and 49 documented components.
- Sheet accepted and returned a changed name, stayed open through Save, and
  closed through Done with the value preserved.
- Item's Manage button returned `Manage Ada selected.`
- Elements preserved a record name and textarea draft across tab switches.
  Accordion and Collapsible controls worked, and the bounded Scroll Area
  had content taller than its viewport.
- Data Table filtered to Beta and Alpha. A row action opened the Sheet editor;
  saving `Alpha verified` changed the displayed table record after closing
  the panel. All edits were confined to the example session state.

The online checks are separate from the installed-package browser suite.
They were completed in the real Chrome browser against the public site after
the deployment reboot. Default dark controls and page layout were visually
inspected. Package checks covered the broader cross-browser appearance and
interaction-state comparisons.

Publication, documentation merge, installed-package acceptance and live-site
acceptance are complete. Existing horizontal-Tabs, Sheet RTL and local-table
scope limits remain documented in the release notes.
